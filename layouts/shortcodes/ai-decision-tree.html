DECISION TREE how I decide when to reach for it
PRIMARY PATH if (I know what I want and an AI agent can do it)
→ Structure the implementation. Let the model generate. Revise, review, intervene manually.
COMMON if (I know what I want but no AI agent is good enough)
→ Gather resources. Refine the idea with an LLM. Implement manually.
EXPLORATORY if (I don't know what I want)
→ Prompt the AI for a general direction. Transition into one of the paths above.
TRIVIAL if (everyday random search)
→ Just prompt the AI.
